# Enterprise EMS – Frontend

React 19 + Vite + Tailwind 4. Talks to the Express/Mongoose backend in `/server`.

```
npm install
cp .env.example .env     # VITE_API_BASE_URL=http://localhost:5000/api
npm run dev              # http://localhost:5173
```

Backend: `cd server && npm install && npm run seed && npm run dev`

Pages: Login · Admin/Employee dashboards · Employees · Departments · Attendance ·
Leaves · Schedules · Notifications · Messaging · Reports · Settings · Profile
